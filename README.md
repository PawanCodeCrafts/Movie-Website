# 🎬 CineVault — Movie Discovery Website  

## 🌐 Live Demo

**Visit CineVault:** [View Live Website](https://YOUR-USERNAME.github.io/cinevault-movie-website/)

**Discover movies. Explore stories. Find your next favorite.**

CineVault is a modern, responsive movie discovery website built using HTML, CSS, JavaScript, and Bootstrap 5. It features a cinematic dark theme with purple accents, movie collections, TV shows, genre browsing, and a dedicated About page.

## ✨ Features

- 🏠 **Homepage** — Hero carousel and featured movie collections.
- 🎥 **Movie Collections** — Trending and popular movies with posters and ratings.
- 📺 **TV Shows** — A dedicated section for popular television shows.
- 🔎 **Movie Search** — Search for movies by title.
- 🎭 **Genre Browsing** — Explore movies by genre.
- 📄 **About Page** — Learn more about CineVault.
- 📱 **Responsive Design** — Bootstrap grid for mobile, tablet, and desktop screens.
- 🎨 **Modern UI** — Dark navy background, purple accents, and interactive hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Make sure the `images` folder contains the movie posters referenced in your HTML.
4. Open `index.html` in your browser, or run the project using the VS Code Live Server extension.
